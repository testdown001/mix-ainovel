{reference_materials}

目标是保留读者愿意追下去的原因：在意人物 → 等待变化 → 带进展的蓄势 → 有分量的兑现 → 情绪余波与新的牵挂。
单本也要提炼具体机制，不能只写“参考原作风格”。多本必须在同一条人物因果线上互补，不能轮流套剧情、每本各占几章，也不能把所有风格平均。

按系统提供的 JSON Schema 输出，字段含义如下：
- narrative_strategy：每本各贡献什么，为什么能组合成同一个故事发动机；不预设新书人物与题材。
- style_fingerprint：统一叙事声音，明确视角距离、长短句如何随处境变化、信息如何释放；遵守新书已选视角与人物声线。
- reader_loop：desire（读者在意的人物得失）、promise（值得等待的变化）、pressure（有进展的阻力与代价）、payoff（由选择触发的具体回报）、aftereffect（兑现后的关系/处境变化如何延续牵挂）。不能全是“提升张力、增加爽点”之类形容词。
- structure_references：每本恰好一项，from 为资料中的原始书名；role 写主要分工，take 写可迁移机制，adapt 写如何转换为新人物的选择与后果，evidence 写依据的记忆卡/结构/桥段分析。即使资料不足也保留该书并写明不足，不杜撰。
- conflict_resolution：列出参考之间实际存在的矛盾及取舍，如高频笑点与严肃余波的适用边界、快节奏与悬念延迟的协调方法。只有单本时说明它与新书设定/人物声线的优先级。
- blended_pacing：以事件与读者期待的成熟度决定蓄势和兑现，兼容关系戏、日常戏、低谷与收束章；不规定固定几章一个高潮。
- dialogue_style：统一的对白原则及人物差异，不要求所有人物同一腔调或固定对白占比。
- scene_rhythm：不同场景的具体职责与衔接，避免每场都完整走一遍抑扬循环。
- key_techniques：可执行的手法及适用条件，安静的关系变化同样可以形成回报。
- avoidance_list：不复刻的事件链、专有设定和措辞；资料未支持的标志性元素不能编造。
- evidence_limits：区分检索/书评分析与原文实证，明确缺失信息。没有原文不能声称读完整本书，AI 仿写不能当作原文证据。

最终自查：是否每本都有明确贡献或资料不足说明？是否给出了统一声音与冲突取舍？是否既有兑现又留情绪余波，而不是一直吊胃口？是否把人物关系、尊严、归属等情感回报纳入动力？仅输出 JSON。
