# 第三批：情感审校、局部修订和连续章节盲读

本批把情感审校接入已有生成步骤，并给作者提供原句、修改理由和修订对照。目标是减少机械解释和反复润色造成的声音丢失；文学效果仍须用真实连续章节盲读验证，代码测试不能代替读者判断。

## 运行行为

- 标准模式已有的综合修订调用改为结构化局部修订，不新增一次前台评审调用。先识别人物得失、选择依据、情绪转折、事件余波、言外之意，再提出修改；没有问题可以返回空修改。
- 每次最多 6 处，原文定位必须唯一、互不重叠，累计替换范围不超过全文 35%。不接受整章重写、虚构定位或需要补充前文才能判断的问题。任何一处无效，本次修改整体不应用。
- 综合修订标出的有效精彩原句会传入后续精修、润色和人味化提示。规则修复、精修、润色、扩写、密度压缩和二次评分修订若抹掉这些原句，保留该步骤之前的稿件。事实校对及最终字数约束仍优先；纠错后失效的旧原句不会被恢复。
- 被保护机制拦回的润色带 `applied: false`，沿用现有附加润色费用退回机制。
- 标准、快速模式的后台分析在派发时绑定最终稿；文学模式在压缩和实体别名纠正后才评审。异步结果落库前再核对原文，避免作者编辑期间把旧稿评语写到新稿上。
- 质量诊断阅读完整章节，超出 30000 字明确标记无法评估，不截取首尾后推断中段情绪。近期材料只有摘要时不据此判断开头句式或结尾套路。
- 读者模拟仍用 3 位读者，固定包含情感读者与文笔读者，第三位按章节功能选择。移除“至少增加 1–2 个爽点”的固定建议；失败结果不计为中等满意度。
- 写作台的版本选择区增加“情感与节奏审校”折叠面板，区分完成稿评语与修订前记录，展示值得保留的表达和局部修订对照。后台结果可在重新载入章节后查看。

未启用综合修订或该步骤因预算跳过时，不凭空声称已识别精彩段落。快速与文学模式本批获得完整正文的情感诊断，但不额外插入标准模式的局部修订流程。模型调用次数不增加，完整正文评审的输入 token 会比原先首尾摘录增加。

报告保存在版本 `metadata.review_summaries`，包含来源正文 SHA-256、原文引用、修订前后片段及退回原因。无需数据库迁移或新增生产配置。

## 连续章节盲读

新增 `backend/run_serial_bench.py`，读取同一前情、相同章节区间的两个版本。它评估实际连续写出的正文，不会把原 `run_bench.py` 中独立重复生成的样本当作连载。

准备两个隔离的小说项目，复制同一蓝图、前情和起始人物状态；固定模型、生成参数和大纲，仅改变本批开关/代码版本。每边连续生成并采用至少 3 章，等采用后的记忆任务完成再生成下一章。保留模型、版本、参数和生成时间记录供揭盲后核对，不要混入盲读正文。

导出 UTF-8 JSON：顶层 `context` 为共同前情，`versions` 恰好两项。每项含 `source`（揭盲用标签）和 `chapters`；每章含 `number` 和 `content`。章节必须连续且按顺序排列，每边 3–8 章；单章最多 20000 字，两边正文合计最多 120000 字，超过时缩小区间，不截断正文。

在 backend 目录运行：

```bash
python run_serial_bench.py ../docs/examples/serial-reading-demo.json --outdir artifacts/serial-demo
```

示例是人工编写的工具演示夹具，不是模型效果数据。默认只生成文件，不调用模型、不写小说数据库。输出目录必须尚不存在，以防覆盖已填的读者意见。

- `reading.html`：匿名 A/B 的连续章节全文，整组固定同一标签，初始顺序随机。
- `ballot.json`：人物牵挂、关系记忆、张弛变化、铺垫兑现、潜台词五项意见及原文依据。
- `packet.json`：匿名评审材料。
- `private/answer-key.json`：来源对应表。只分发阅读页和空白意见表，收齐意见后揭盲。

可选模型评审（两次付费调用，使用当前配置的默认模型，建议评审模型与写作模型不同）：

```bash
python run_serial_bench.py pair.json --outdir artifacts/serial-real --judge --user-id 1
```

两轮按 AB、BA 顺序阅读全部章节，再把胜者和证据标签映射回同一来源。每个可评维度必须引用两边各至少两章的原句；引用不存在、只看单章或请求失败，记为无法评估，不能算平局。两轮不一致时保留分歧，不宣称获胜。`judge.json` 保存两轮证据和逐项结论。

推荐先盲读 3–5 章，至少覆盖一次压力升级、一次选择及后果、一次关系或日常余波；再换题材复验。结果要报告读者人数、逐项偏好和具体片段，不只公布一个综合分。当前第三批验收覆盖流程及防误改机制，尚未取得真实模型连续章节的盲读胜率。
