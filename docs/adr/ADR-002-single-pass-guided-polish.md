# ADR-002：单阶段引导精修

- 状态：已接受
- 日期：2026-08-21
- 对应路线图：M0、M4

## 背景

多轮串行改写会累积语义漂移、削弱作者文风，并造成难以预测的耗时与成本。

## 决策

整章后处理逐步收敛为两次职责明确的调用：

1. 一次结构化诊断，输出问题、证据范围和修订目标；
2. 一次只针对被标记范围的定向精修。

默认不自动覆盖正文。任何改写都以差异预览呈现，并在作者采纳后产生独立修订版本。

## 后果

- 新功能不得新增无证据的串行“再润色”步骤。
- 质量、耗时、token 和采纳率需要按诊断与精修分别记录。
- 旧链路的收敛应在 M4 通过开关灰度完成，失败时可降级为仅诊断。
