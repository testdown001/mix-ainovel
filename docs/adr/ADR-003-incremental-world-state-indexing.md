# ADR-003：增量世界状态索引

- 状态：已接受
- 日期：2026-08-21
- 对应路线图：M0、M1、M5

## 背景

向量检索擅长找语义相近的段落，但不能可靠回答“人物现在在哪、是否受伤、知道什么、持有什么、时间推进到哪里”。对整本书反复全量抽取又会产生不可控成本。

## 决策

以章节确认版本为边界持久化世界状态切片。每条切片关联作品、章节、源版本、父切片、内容哈希与文本证据范围；下一章可从最近的已确认切片继承状态种子。

抽取采取增量策略：仅在定稿或确认版本发生变化时，按差异范围触发异步抽取。人工确认的状态优先级高于自动抽取。

## 后果

- M1 先落地 schema、存储和读取接口；自动抽取、诊断与逆向大纲在 M5 接入。
- 诊断必须引用版本与原文范围，不能只给无来源的结论。
- 状态切片为事实数据，不应把 LLM 的推测直接当成确定事实；需保留来源和置信度。
